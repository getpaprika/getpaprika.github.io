Paprika Client

A free Fabric client with 102 mods for Minecraft 1.20 and 1.21.1. Base finding, a pathfinding bot, PvP mods and a HUD you can arrange yourself.

What makes it Paprika

Most clients have aura and ESP. These are the parts you won't find everywhere.

Base hunting that tells real bases from dungeons

BaseW recognizes villages, dungeons, igloos, witch huts and trial chambers, collects clues like signs with text, pets and concrete, and only warns "guaranteed base" when the evidence adds up. NewChunks, StructureW finders and Breadcrumbs help you follow the trail.

A built-in pathfinding bot

Type #b goto, #b mine or #b farm in chat. Baritone walks, digs, bridges and pillars for you, avoids lava and water, picks up what it mines and can farm crops or mobs on its own.

Two menu styles and your own HUD layout

Use the tabbed menu or the List style with every tab side by side, pick one of 18 themes, set Shift+R style keybinds, and drag your HUD where you want it in the HUD editor.

PvP with a legit option

Kill auras for players, mobs and monsters with an Obvious and a Legit mode, plus TriggerBot, AimAssist, AutoTotem, AutoGap, CrystalAura and WebAura.

Install in a few minutes

If you already play with Fabric mods, you only need step 3.

  1. Install FabricGet the Fabric installer from fabricmc.net and install Fabric Loader for your Minecraft version.
  2. Add Fabric APIDownload Fabric API for the same Minecraft version and put it in your .minecraft/mods folder.
  3. Add PaprikaDownload the Paprika jar for your version above and put it in the same mods folder.
  4. PlayStart Minecraft with the Fabric profile and press Right Shift in game to open the menu.

Questions

Which file do I download?

The one that matches your Minecraft version: the first button for 1.20 and 1.20.1, the second for 1.21 and 1.21.1. Using the wrong one makes Minecraft refuse to start with a version error.

Can I get banned for using it?

On servers that don't allow clients, yes. Mods like the kill auras, Fly or Xray break the rules of most servers. Only use them in singleplayer or on servers that allow it, like anarchy servers.

Does it work with Sodium and other mods?

Paprika is a normal Fabric mod, so it runs next to most other Fabric mods. Xray and a few render mods can behave differently with Sodium.

Where are my settings saved?

In .minecraft/config/paprika.json. It keeps which mods are on, their settings, keybinds, friends, markers and your HUD layout.

Some mods say "MAY NOT WORK!". Why?

Mods like FastMine, ClickTP and Noclip do things servers check for. They work in singleplayer, but many servers move you back or ignore them.
