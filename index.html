Paprika Client

A free, open source Fabric hacked client with 104 mods for Minecraft 1.19 to 26.3. Base finding, a pathfinding bot, PvP mods and a HUD you can arrange yourself.

Get Paprika

Free for Minecraft 1.19, 1.19.4, 1.20, 1.21.1, 1.21.11 and 26.3. Every release and the install steps are on the Install page.

Go to releases →

Needs Fabric Loader 0.15 or newer and Fabric API. Java 17 for 1.19.x and 1.20, Java 21 for 1.21.x, Java 25 for 26.3.

Preview of Paprika

Paprika has two menu styles. Pick one to see how it looks in game.

In the game: Right Shift or Delete opens the menu. Left click turns a mod on, right click opens its settings.

Chat commands

Type these in chat. They're never sent to the server, and anything else starting with # isn't sent either, so a typo won't give you away.

#help
Shows the list of commands in chat.
#c waterMark
Turns the red dye and Paprika Client watermark in the top left on or off.
#m [equation]
A calculator. Supports + - x / and ^ or @ for powers, for example #m 28+6x9.
#a x1 y1 z1 x2 y2 z2
Draws an area between two corners. Use #a ~ x y z to start from where you stand.
#a deleteall
Deletes all your areas.
#friend add [name]
Adds a friend. Kill auras, CrystalAura, BowAimbot, AutoLogout and PlayerW leave friends alone, and FriendW tells you when they're near.
#friend remove [name]
Removes a friend.
#friend list
Shows your friends.
#orgskin
On cracked servers, shows players' real skins (only on your screen).
M
Not a command but a key: opens the marker menu, where you create, color, hide and delete markers.

What makes it Paprika

Most clients have aura and ESP. These are the parts you won't find everywhere.

Base hunting that tells real bases from dungeons

BaseW recognizes villages, dungeons, igloos, witch huts and trial chambers, collects clues like signs with text, pets and concrete, and only warns "guaranteed base" when the evidence adds up. NewChunks, StructureW finders and Breadcrumbs help you follow the trail.

A built-in pathfinding bot

Type #b goto, #b mine or #b farm in chat. Baritone walks, digs, bridges and pillars for you, avoids lava and water, picks up what it mines and can farm crops or mobs on its own.

Two menu styles and your own HUD layout

Use the tabbed menu or the List style with every tab side by side, pick one of 18 themes, set Shift+R style keybinds, save whole setups as presets you can switch between, and drag your HUD where you want it in the HUD editor.

PvP with a legit option

Kill auras for players, mobs and monsters with an Obvious and a Legit mode, plus TriggerBot, AimAssist, AutoTotem, AutoGap, CrystalAura and WebAura.

Account manager

Play under any name with cracked (offline) accounts, and switch back to your real Microsoft account whenever you want. No restart needed.

  1. Open Singleplayer or MultiplayerFrom the title screen, open either one.
  2. Click CrackedThe Cracked button is in the top right. It opens the account manager.
  3. Make an accountClick New account, type a name (3 to 16 letters, numbers or _) and click Create.
  4. Switch to itClick the account in the list. It turns green, which means you're now playing as that name.
  5. Go back to your real accountClick Exit cracked. You're back on your Microsoft account and the green goes away.

Where cracked accounts work

Singleplayer and cracked (offline-mode) servers. On normal online servers you need your real account, because a cracked account has no Microsoft login behind it and the server will kick you.

Your list is saved. The accounts you made stay there, but every time you start Minecraft you begin on your real account.

Delete an account with the red trash can next to it. If you were using it, you go back to your real account.

Questions

Is it safe?

Yes. Paprika is a normal Fabric mod. It doesn't collect your data or install anything, and the only thing it connects to besides your Minecraft server is Mojang's own skin servers, and only when you turn on Real skins. You don't have to take our word for it: a .jar file can be decompiled back into Java with a free decompiler, so anyone can open Paprika and read exactly what the code does. The full source code of every version is also on the Install page, so you can read it or build the jar yourself.

Which file do I download?

On the Install page, pick the one that matches your Minecraft version. Each file says which versions it's for, for example the 1.21.1 one works on 1.21 and 1.21.1. Using the wrong one makes Minecraft refuse to start with a version error.

Can I get banned for using it?

On servers that don't allow clients, yes. Mods like the kill auras, Fly or Xray break the rules of most servers. Only use them in singleplayer or on servers that allow it, like anarchy servers.

Does it work with Sodium and other mods?

Paprika is a normal Fabric mod, so it runs next to most other Fabric mods. Xray and a few render mods can behave differently with Sodium.

Where are my settings saved?

In .minecraft/config/paprika.json. It keeps which mods are on, their settings, keybinds, friends, markers and your HUD layout.

Some mods say "MAY NOT WORK!". Why?

Mods like FastMine, ClickTP and Noclip do things servers check for. They work in singleplayer, but many servers move you back or ignore them.
