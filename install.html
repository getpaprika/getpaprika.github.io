Install in a few minutes

If you already play with Fabric mods, you only need step 3.

  1. Install FabricGet the Fabric installer from fabricmc.net and install Fabric Loader for your Minecraft version.
  2. Add Fabric APIDownload Fabric API for the same Minecraft version and put it in your .minecraft/mods folder.
  3. Add PaprikaDownload the Paprika jar for your version from the list above and put it in the same mods folder.
  4. PlayStart Minecraft with the Fabric profile and press Right Shift in game to open the menu.
